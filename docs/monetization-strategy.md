# 収益化戦略（2026-10 改訂）

> 目的：`highlight-compass.com` を **広告（AdSense）＋配信アフィリエイト**で収益化する。
> このドキュメントは毎朝の自動SEO監視ループ（`docs/seo_daily_report.md` を読むRoutine）の**北極星**。
> 数字は 2026-10-05 時点の GSC/GA 実測に基づく。更新履歴は本文末尾。
> ※ 2026-07 初版は「W杯2026決勝(7/19)までに広告ON」という当時のタイムラインだった。W杯は閉幕し、
>   現在は**欧州シーズン真っ只中＋代表ウィーク（ネーションズリーグ）**が主戦場。下記は現状に合わせた改訂版。

## 現状（2026-10-05 実測）
- GSC: 表示 **1,169/週**・クリック **37/週**・平均順位 **17.3**・CTR **3.2%**
- GA: **257ユーザー/28日**・312セッション。チャネル別では **AI Assistant が滞在620秒（最長・最良エンゲージ）**、Organic 204セッション。
- 最大の流入源は **ネーションズリーグ**（`/league/nations-league.html` 47クリック・平均6.3位）。クラブ/リーグページも堅調な基盤。
- 収益基盤: AdSense `ca-pub-7948789271209448`、`ads.txt` 設置済み。CTAクリックは GA4 `stream_cta_click` で計測済み。

## 🚧 収益が ¥0 の構造的ボトルネック（＝オーナー対応が必要・最優先）
現状、技術的な器はすべて完成している。**空欄を埋めれば即収益化**する。埋まるまでは安全側（広告非表示・公式リンク）にフォールバックする設計。

### ① AdSense 広告スロットが未設定 → 全広告枠が自動非表示（収益 ¥0）
- `data/ads.json` の `adSlot` が空のため、全ページの広告枠が「空枠ガード」で非表示になっている。
- **オーナーの作業**：
  1. AdSense アカウントが「**承認済み**」かを確認（審査中だと配信されない）。
  2. AdSense管理画面で「ディスプレイ広告」ユニットを1つ作成し、**広告スロットID（数字10桁程度）**を取得。
  3. `data/ads.json` の `adSlot` にそのIDを記入（またはClaudeに「adSlotは◯◯」と伝える）。
  4. 再ビルド＆デプロイで**全ページの広告枠（実装済み）が一斉に有効化**される。

### ② 配信アフィリエイトのリンクが未設定 → CTAは公式リンク（nofollow・収益化なし）
- `data/affiliate.json` の `daznUrl` / `unextUrl` / `wowowUrl` が空のため、配信CTAは各社公式リンク（nofollow・PR表記なし）で出ている。
- 大会別の出し分けは実装済み（`LEAGUE_SERVICE`）：ラ・リーガ/プレミア/エールディヴィジ→**U-NEXT**、CL/EL/カンファレンス→**WOWOW**、セリエA/ブンデス/リーグアン/J/代表/NL等→**DAZN**。
- **オーナーの作業**：
  1. 各社のアフィリエイトを ASP（A8.net / バリューコマース 等）経由で**提携申請**する。
     - DAZN・U-NEXT・WOWOW はいずれも主要ASPで取り扱いあり。
  2. 承認後、各社の**成果リンク（トラッキングURL）**を取得。
  3. `data/affiliate.json` の該当キー（`daznUrl`/`unextUrl`/`wowowUrl`）に記入（またはClaudeに伝える）。
  4. 記入されたサービスのCTAは自動で成果リンク＋`rel="sponsored nofollow"`＋**PR表記**に切り替わる（景表法・ステマ規制に準拠）。空のサービスは公式リンクのまま。

> 計測の利点：提携前から GA4 `stream_cta_click`（service / competition / affiliate）で「**どの大会・どのサービスのCTAが押されているか**」が見える。
> → クリックが多いサービスから優先的に提携申請すれば、最短で収益に繋がる。まず **DAZN（NL/代表/セリエ/ブンデス等をカバー＝現在の主力導線）** が有力候補。

## 収益を伸ばす3つのレバー（器が埋まった後の継続施策）
1. **広告を出す（①）** — これが無いと全てゼロ。最優先。
2. **集客（PVを増やす）** — データ駆動SEO。現在の勝ち筋は **ネーションズリーグ**（最大流入・高CTR）。CL/EL/代表の情報系クエリ・AI引用の受け皿も整備済み。
3. **1訪問あたりPV/RPMを上げる** — 試合↔国↔クラブ↔ガイドの内部リンク回遊、広告配置の最適化。

## 継続SEO施策（毎朝ループで回す）
- **"あと一歩"（順位8〜20）を1ページ目へ**：`seo_daily_report.md` のクエリで順位8〜20を特定 → 該当ページの見出し/内容/内部リンクを強化。
- **CTR改善**：表示が多いのにCTRが低いページの title/description を検索意図に最適化。
- **AI発見性**：構造化データ（VideoObject/FAQPage/SportsEvent 等）・`llms.txt`・RSS を維持拡充（AI Assistant経由は最長滞在＝高価値）。
- **鮮度**：新しい試合ハイライトを取りこぼさず即掲載（自動パイプライン）。
- **回遊**：内部リンクを増やし、1訪問の広告表示回数（≒収益）を増やす。

## 毎朝ループの判断基準
- 収益 ¥0 が続く場合、まず「**広告が実際に配信されているか**（`adSlot`設定・AdSense承認状態）」を疑い、レポート冒頭で警告する。
- 前日比で表示急伸のクエリ/ページ → その周辺コンテンツを即補強（旬を逃さない）。
- 順位8〜20 かつ 表示が多いページ → title/description/内部リンクを最適化（安全なら実装まで、割れる判断は提案に留める）。

## KPI（毎週チェック）
- **広告配信：ON/OFF（最優先）** ／ 推定収益（AdSense管理画面）
- **アフィリエイト：提携済みサービス数** ／ `stream_cta_click` のサービス別クリック数
- GA：PV/日、セッション、PV/セッション
- GSC：表示、クリック、CTR、平均順位、順位8〜20クエリ数
